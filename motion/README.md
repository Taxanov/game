# Моушн BAVIX

## Интро логотипа (`logo-intro/`)

Ролик «identity.build» в фирменных цветах: `> init bavix` → чертёж → сборка → удар → финал.
Каждый кадр — функция времени, поэтому рендер покадрово точный. Тайминг совпадает со звуком (`logo-intro/audio.m4a`):
щелчки клавиш 0.95–1.8 с, удар 2.25 с, главный удар 5.25 с, волна 7.0–7.6 с.

Посмотреть в браузере: `logo-intro/index.html?w=1920&h=1080&end=em&play`
- `w`, `h` — размер кадра; `end=em` — изумрудный финал, `end=dark` — тёмный;
- `t=5.25` — заморозить кадр (для скриншотов), `play` — проиграть по кругу.

## Рендер

```
npx http-server -p 8080 .          # из корня репозитория
node motion/render.js              # все форматы: 16x9 4x5 9x16 1x1
node motion/render.js 9x16         # только один
```

Нужны Node, Playwright и ffmpeg. На каждый формат получается три файла в `motion/out/`:
`bavix-intro-<формат>-emerald.mp4`, `bavix-intro-<формат>-dark.mp4` (9 с) и `bavix-sting-<формат>.mp4` (3.6 с),
плюс PNG финальных кадров. Видео в git не хранятся.
