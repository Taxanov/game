# Моушн BAVIX

## Кусочки продукта (`product/`) — основная версия

- 0–2.25 с — на щелчки звука появляются фрагменты интерфейсов: сделка в CRM, Telegram-бот, график заявок,
  экран приложения, воронка, ИИ-ассистент, сайт. Камера медленно наезжает на коллаж;
- 2.25 с — на удар фрагменты схлопываются в точку, из неё вырастает шеврон X;
- 2.25–5.25 с — камера отъезжает, буквы съезжают по рельсам сетки и встают на места на главный удар;
- дальше подпись и финал `em` (портал в изумрудный) или `white` (волна по буквам).

Посмотреть: `product/index.html?w=1920&h=1080&end=em&play` · рендер: `SCENE=product node motion/render.js`

## Суперграфика (`supergraphic/`)

Направление C из брендбука: буквы логотипа как огромные обрезанные формы, как швейцарский плакат.
Референсы: кинетические айдентики DIA и Studio Dumbar, сборка из фрагментов (Dufry), «логотип как портал» (Bolt.new).

- 0–2.25 с — плакатные кадры: гигантские Λ, V, X, B, I на белом, графитовом и изумрудном, склейки на щелчки звука;
- 2.25–5.25 с — одно движение камеры: отъезд от шеврона X, буквы съезжают по рельсам сетки и сходятся в логотип на главный удар;
- 5.5–7 с — подпись по словам;
- 7–9 с — финал `em`: шеврон X растёт и заливает кадр изумрудным; финал `white`: изумрудная волна по буквам.

Посмотреть: `supergraphic/index.html?w=1920&h=1080&end=em&play` · рендер: `SCENE=supergraphic node motion/render.js`

## Интро «identity.build» (`logo-intro/`) — первая версия

Ролик «identity.build» в фирменных цветах: `> init bavix` → чертёж → сборка → удар → финал.
Каждый кадр — функция времени, поэтому рендер покадрово точный. Тайминг совпадает со звуком (`logo-intro/audio.m4a`):
щелчки клавиш 0.95–1.8 с, удар 2.25 с, главный удар 5.25 с, волна 7.0–7.6 с.

Посмотреть в браузере: `logo-intro/index.html?w=1920&h=1080&end=em&play`
- `w`, `h` — размер кадра; `end=em` — изумрудный финал, `end=dark` — тёмный;
- `t=5.25` — заморозить кадр (для скриншотов), `play` — проиграть по кругу.

## Рендер

```
npx http-server -p 8080 .          # из корня репозитория
node motion/render.js              # все форматы: 16x9 4x5 9x16 1x1
node motion/render.js 9x16         # только один
```

Нужны Node, Playwright и ffmpeg. На каждый формат получается три файла в `motion/out/`:
`bavix-intro-<формат>-emerald.mp4`, `bavix-intro-<формат>-dark.mp4` (9 с) и `bavix-sting-<формат>.mp4` (3.6 с),
плюс PNG финальных кадров. Видео в git не хранятся.
